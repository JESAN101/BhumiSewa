# BhumiSewa

## GIS-Based Digital Land Parcel and Land-Use Management Platform

BhumiSewa is a GIS-based platform designed to support local-government
land information, land-use visualization and analysis, selected
land-related digital services, and spatial decision support.

## Project Status

Development started after completion of the 7th semester.

## Technology Stack

- Frontend: Next.js + TypeScript
- Backend: Django + Django REST Framework
- Database: PostgreSQL + PostGIS
- GIS: Leaflet + GeoDjango
- GIS Analysis: Python GIS libraries
- Authentication: Django authentication + OTP
- Payment: Nepal-supported payment gateway
- Version Control: Git + GitHub

## Main Modules

- User Authentication
- Parcel Search and Information
- Interactive GIS Map
- Land-Use Management
- Land-Use Change Detection
- Digital Land Services
- Application Tracking
- Payment
- Surveyor Booking
- Municipality Dashboard
- Surveyor Dashboard
- Admin Dashboard
- Nepali / English Language
- Light / Dark Theme

## Development Approach

The project will follow the Software Development Life Cycle (SDLC):

1. Problem Identification
2. Feasibility Study
3. Requirements Analysis
4. System Analysis
5. System Design
6. Development
7. Testing
8. Deployment
9. Evaluation
10. Maintenance

## Project Goal

The goal is to develop a practical GIS-based system that can help
citizens and local government interact with land-related spatial
information and selected digital services through a unified platform.
